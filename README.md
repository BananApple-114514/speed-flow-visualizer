# 流速可视化工具

一个用于 RPE NEXT 的谱面编辑器 Mod，用于可视化流速与 Note 位移之间的关系。

## 功能

- 流速与节拍关系图
- Note 位移与节拍关系图
- 自定义位移原点
- 图表缩放与面板调整
- 位移图刻度精确度设置
- 支持流速事件缓动曲线的可视化计算

## 当前版本

**v1.3.2**

## 安装

1. 在 Releases 页面下载最新的 `.rpenmod` 文件。
2. 按照 RPE NEXT 支持的 Mod 安装方式导入。
3. 启用 Mod 后，根据界面提示使用。

## 说明

本项目用于辅助谱面编辑和流速分析。不同谱面格式保存的事件数据可能存在差异，实际效果请以 RPE NEXT 中的运行结果为准。
